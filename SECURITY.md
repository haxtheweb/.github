# Security Policy

## Reporting a vulnerability
Please **do not** report security vulnerabilities in public issues.

Report them privately using GitHub's [private vulnerability reporting](https://github.com/haxtheweb/issues/security/policy) on the affected repository (Security tab → "Report a vulnerability"), or email hax@psu.edu

Include the affected repo and version, steps to reproduce, and the potential impact. We'll acknowledge your report and keep you updated as we work on a fix.

## Supported versions
Security fixes are made against the latest release of each HAX package.
