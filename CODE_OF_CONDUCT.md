# Code of Conduct

HAX The Web adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct for all repositories, issue queues, and community spaces, including Discord.

In short: be welcoming, be respectful, assume good intent, and focus on what's best for the community. Harassment and exclusionary behavior are not tolerated.

## Reporting
If you experience or witness unacceptable behavior, contact the maintainers at hax@psu.edu . Reports are handled confidentially.
