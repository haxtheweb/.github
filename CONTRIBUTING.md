# Contributing to HAX The Web

Thanks for helping improve HAX! These guidelines apply to every repository in the haxtheweb organization unless a repo has its own CONTRIBUTING file.

## Report issues in one place
All bugs, feature requests, and questions go to the **[unified issue queue](https://github.com/haxtheweb/issues/issues)**, even if they concern a specific repo. Inside any HAX space you can also open Merlin and type "Issue" to start a report.

## Set up a development environment
```bash
npm install @haxtheweb/create --global
hax start
```
The CLI walks you through creating a HAXsite or a web component. See the [HAX documentation](https://haxtheweb.org) for details.

## Making changes
1. Find or open an issue in the unified queue and mention that you're working on it.
2. Fork the relevant repo and create a branch.
3. Follow the DDD design system for any styling, and keep components accessible (WCAG 2.0 AA).
4. Open a pull request that links the issue and describes what changed and how you tested it.

Maintainers review every PR before merging.

## Talk with us
Join us on [Discord](https://discord.gg/EKYJAjqGhf) or watch walkthroughs on [YouTube](https://www.youtube.com/@haxtheweb).

By participating you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
